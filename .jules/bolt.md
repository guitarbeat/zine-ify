## 2026-06-23 - Map.get() vs findIndex() Missing Value Fallback
**Learning:** When optimizing React components by replacing `O(n)` array lookups (`Array.findIndex`) with pre-computed `O(1)` Hash Maps, `findIndex` natively returns `-1` if an item is not found, whereas `Map.get()` returns `undefined`. This difference can break boolean boundary conditions (e.g., `-1 < array.length` is true, but `undefined < array.length` is false).
**Action:** When converting `findIndex` to `Map.get()`, always append the nullish coalescing operator `?? -1` (e.g., `const index = MAP.get(id) ?? -1;`) to strictly preserve the original missing-value behavior and prevent logic regressions.
