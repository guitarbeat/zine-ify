## 2026-04-18 - Accessible Focus States and Icon Buttons
**Learning:** Replaced unaccessible `focus:outline-none` on interactive elements (like close modals and custom icon buttons) with high-contrast, punk-themed focus ring classes. Added `aria-label`s to icon-only buttons to ensure they're understandable by screen readers. A test (`accessibility_buttons.spec.js`) explicitly checks for these focus classes to ensure regressions don't occur.
**Action:** Always provide visible focus rings for keyboard navigability. Use classes like `focus-visible:outline-4 focus-visible:outline-black focus-visible:outline-dashed focus-visible:outline-offset-4 focus-visible:!bg-yellow-300 focus-visible:!text-black` to override global resets. Ensure any icon-only button contains a clear `aria-label`. Ensure Playwright tests assert on these specific accessible class names rather than the lack thereof.
