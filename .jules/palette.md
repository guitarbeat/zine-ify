## 2026-06-14 - Accessible Buttons in ActionOrb and BookletPreview
**Learning:** Icon-only buttons created programmatically often miss accessible labels. While a `title` attribute gives a native hover tooltip, an explicit `aria-label` guarantees screen-reader compatibility. Additionally, for elements whose `disabled` state changes dynamically via JavaScript, setting `aria-disabled` alongside the `disabled` property ensures accurate screen-reader announcements.
**Action:** When creating utility buttons or interactive components programmatically, always ensure `aria-label` and `title` are populated from the label. When toggling the `disabled` property, mirror the state to `aria-disabled`.
