## 2026-04-23 - Interactive Element Focus Rings & Localized Loading States
**Learning:** This app heavily relies on global "processing" modals for async actions like PDF generation, leaving trigger buttons themselves without localized feedback. Additionally, many interactive elements actively suppressed keyboard focus rings using `focus:outline-none`.
**Action:** Always verify that actionable elements use localized loading feedback (e.g. `aria-busy` and an inline spinner on the button itself) during long-running tasks. Strip out anti-pattern `focus:outline-none` classes and replace them with high-contrast `focus-visible` styles (`outline-4 dashed black`, `bg-yellow-300`) to ensure robust keyboard accessibility.
